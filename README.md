# Yang Liu — Portfolio

The source for Yang Liu's AI builder portfolio. The first implementation covers the homepage hero, a Meowsformer system-flow preview, and the opening "How I Build" section.

## Local development

```bash
npm install
npm run dev
```

## Validation

```bash
npm test
npm run check
npm run build
```

The Dragon Boat Training portal is available at `/dragon-boat-training/` under the configured GitHub Pages base path. Its implementation and product documents live in `dragon-boat-training/`; see the [current status and development handoff](dragon-boat-training/CURRENT-STATUS.md) for verified scope and next steps.

The site is configured for the GitHub Pages project URL at `https://jeoker.github.io/hey-yang-liu.github.io/`. A future custom-domain migration will require updating the Astro `site`/`base` settings and restoring `public/CNAME` together.
