# Yang Liu — Portfolio

The source for Yang Liu's AI builder portfolio. The first implementation covers the homepage hero, a Meowsformer system-flow preview, and the opening "How I Build" section.

## Local development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run check
npm run build
```

The site is configured for `heyyangliu.io`, matching the current GitHub Pages `CNAME`. The final public domain still needs confirmation before launch.
