# P2.1 验收与等待实测

## 环境与方法

2026-09-02（America/New_York），在原有隔离 Google 测试赛季、二十二名虚构队员、三场公开训练中测试。对比 Version 8（`0.4.0-p2`）和 Version 9（`0.5.0-p2.1`），使用同一首场、同一虚构队员及相同动作顺序。两轮普通报名／换侧／取消，管理改名与恢复各一次；首次加载和登录各一次。原始去身份报告保留在被 Git 忽略的 `backend/.build/`，复现入口为 [live-p21-timing.mjs](live-p21-timing.mjs)。

计时从客户端开始执行 API 链，到响应解析及结果核对完成，包含重定向和网络等待；不包含人工确认时间。它不等同于浏览器点击至渲染完成的精确耗时，也不等同于服务器锁占用。每条动作的 Google 请求串行执行，测试网站打开时另有页面读取，未模拟严格受控网络或真实多人负载。小样本只能支持本轮观察，不能形成延迟保证。

## 实测结果

| 场景 | 优化前请求数 | 优化后请求数 | 优化前耗时 | 优化后耗时 |
|---|---:|---:|---:|---:|
| 报名，两次 | 每次 2 | 每次 1 | 13.97／12.99 秒 | 9.63／8.45 秒 |
| 换侧，两次 | 每次 2 | 每次 1 | 12.28／20.07 秒 | 12.54／8.32 秒 |
| 取消，两次 | 每次 2 | 每次 1 | 13.97／16.98 秒 | 14.71／15.14 秒 |
| 登录并自动展开工作区 | 5 | 登录入口 2，打开队员工作区再 1 | 26.93 秒 | 入口 9.12 秒，工作区 6.91 秒 |
| 改名 | 3 | 1 | 16.86 秒 | 12.17 秒 |
| 恢复姓名 | 3 | 1 | 23.93 秒 | 12.42 秒 |
| 首页首次加载 | 2 | 2 | 17.20 秒 | 17.79 秒 |
| 首次读取训练详情 | 1 | 1 | 7.58 秒 | 3.77 秒 |
| 有效名单缓存下读取训练详情 | 1 | 1 | 7.89 秒 | 6.37 秒 |

六次普通操作的均值从 15.04 秒降至 11.47 秒；一轮换侧和一轮取消没有变快。首次首页请求链没有改变，不能把某次读取快慢归因为本轮代码。登录进入名册的完整 API 链由五次降为三次，本轮合计约 16.02 秒；只比较登录入口的 9.12 秒会夸大收益。

优化后的普通写响应为约 1.5–1.7 KB，首次管理工作区约 8.4 KB，改名／恢复约 6.8 KB，按解码后的 UTF-8 JSON 字节数计算，不含 HTTP 头、压缩或重定向流量。名单版本不变时不回传全量成员；改名推进名单版本，因此返回更新后的名册。未测 Version 8 响应字节数，也未单独测锁等待与锁持有时间，不据此声称锁性能提高；锁剖析和持续负载仍需后续实测。

## 自动与真实验证边界

91 项本地测试通过，覆盖已有容量、顺序、换侧、截止、停用、恢复与冲突规则，并新增当前视图与不可变结果分离、视图生成失败后的成功语义、旧请求重放、十分钟缓存边界、按需加载、正常保存无额外读取、刷新时保留输入、晚到视图版本隔离和退出后私人数据清理。Astro 检查与构建、Apps Script 单文件构建通过。

真实 API 两轮均结束成功：没有遗留有效测试报名，改名已恢复，会话已撤销；保留历史报名及审计。脚本失败不会自动清空数据，需先核对原请求。

真实浏览器的双端检查及最终部署状态以 [CURRENT-STATUS.md](../CURRENT-STATUS.md) 为准。首次页面读取在计时脚本运行期间出现过 `SERVICE_BUSY`，停止该轮写入后用页面重试入口读取成功；减少请求并未消除 Google 延迟或脚本锁竞争。

Safari、真实手机、长期配额／持续负载，以及浏览器精确渲染耗时尚未验证，不属于本轮已通过的证据。
