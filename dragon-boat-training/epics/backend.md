# BE：后端与数据服务

> 状态：BE-01 的 P0 服务已真实部署，并通过健康检查、会话、幂等写入、退出及实际 Pages 来源验收。BE-02 已交付凭据版本、脚本锁、系统请求去重／恢复与审计基础，业务实体归属和版本冲突随 P1 接入。BE-03 至 BE-08 尚未开始。

[Epic 总览](README.md) · [产品规则](../README.md) · [后端规格](../google-sheets-backend-spec.md)

## 目标与职责

交付唯一的 Apps Script 业务服务，负责公开及管理接口、Google 文件访问、数据一致性、自动任务和公开数据筛选。所有会改变报名、排座、排期或赛季状态的判断都在此完成，包括管理员发起的操作。

不实现网页控件；不向浏览器交付 Google 凭证或通用单元格写入能力。管理 Code 的人工登记与交接属于本 Epic 的部署说明，不额外建设人员审批或在线权限管理产品。

## 工作包

“前置”表示所需能力或契约已可用，不要求对方整个 Epic 完成。各包详细行为遵循后端规格，交付时同步真实接口样例。

| BE-02 | 统一会话、权限检查、输入安全、实体归属校验；锁、请求去重、版本冲突、只追加日志与可恢复写入基础 | BE-01 | 有效 Code 可管理，过期及停用立即失效；错误归属、旧版本和重复请求不产生额外副作用；最小写入中断可恢复 |
| BE-03 | 系统表与赛季初始化、绑定校验及锁定、自动激活与默认赛季；Form 导入和补扫、队员维护、名单版本与十分钟共享缓存 | BE-02 | 错误绑定不激活；重试及新回答不重复、不串季、不覆盖人工修正；多客户端共用缓存，资格写入校验不依赖缓存 |
| BE-04 | 模板与周草稿生成、首次确认及预约开放、单场增补发布、训练修改与取消、日期及赛季边界检查 | BE-03 | 未确认及新增草稿不可公开读取或报名；整周发布不露半周；增补不改既有报名，重复生成不恢复已删除场次 |

| BE-08 | 管理健康与日志读取、受控同步／归档重试的完整交付；部署、授权、触发器、参数、人工 Code 交接及恢复说明；综合验证 | 各业务包的日志与恢复能力逐步接入；最终验收依赖 BE-01 至 BE-07 | 管理员能定位失败并受控重试；部署更新不清空业务数据；真实 Google 集成、故障恢复和交接步骤可复现 |

## 与其他 Epic 的交接

- 给 FE 提供公开安全字段、训练状态、名单有效期、当前版本、历史快照及必要的业务提示；给 ADM 提供草稿、配置、操作结果和恢复状态，不要求页面拼接原始 Sheet 行。
- 接口样例覆盖成功、候补、拒绝、冲突和结果尚未确定等状态。公开／管理身份边界由服务端验证，隐藏按钮不是权限检查。
- BE-03、BE-04、BE-07 产生的状态必须可通过界面所需读取接口观察；日志、重试与管理读取随相应业务包提供，不能全部拖到 BE-08 才让 ADM 联调。

## 完成条件

所有工作包及对应后端验证组通过，并分别与[队员前端](frontend.md)、[管理员页面](admin.md)联调。共享业务规则只有一套；真实私有 Google 测试资源、时间边界、并发与中断恢复均有结果记录。部署说明明确队伍账号所需权限、重新授权及触发器恢复步骤，未完成的真实验证不能由本地模拟代替。
